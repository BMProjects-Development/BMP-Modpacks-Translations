# Улучшение "Исток Ars"

<ItemImage id="ars_nouveau:sourcestone" scale="3" />

Одно из первых улучшений мирового двигателя, которое Вы можете открыть - это <Color id="light_purple">"Исток Ars"</Color>. Это дополнительное улучшение позволит Вам направить <Color id="light_purple">Источник</Color> в <Color id="gold">контроллер мирового двигателя</Color>.

Для начала Вам понадобится принести <Color id="green">заполненный кувшин с Истоком</Color> и <Color id="light_purple">жезл Владычества</Color>, чтобы связать поток <Color id="light_purple">Истока</Color> в контроллер из сосуда. В дальнейшем Вы сможете использовать <Color id="light_purple">"Реле источника: передача"</Color>, чтобы передавать источник прямо из Вашей базы.
