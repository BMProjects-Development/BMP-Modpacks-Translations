# <Color id="gold">Улучшение "Нагреватель"</Color>

<ItemImage id="mekanism:resistive_heater" scale="3" />

<Color id="green">"Нагреватель"</Color> - это необходимое улучшение, которое повзоляет Вам подавать тепло в <Color id="gold">контроллер мирового двигателя</Color>.

Рекомендуется использовать  <Color id="green">устойчивый нагреватель</Color>, чтобы Вы могли установить точное количество энергии для создания достаточного количества тепла. Позже Вы даже сможете использовать реактор для подачи тепла.

Это улучшение разблокирует <Color id="gold">зарядную сферу</Color> для продолжения развития в <Color id="gold">Powah</Color>.
