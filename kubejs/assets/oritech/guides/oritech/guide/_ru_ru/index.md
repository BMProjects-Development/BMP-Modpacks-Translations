<Color id="aqua">Ускоритель частиц</Color> — это продвинутая установка, используемая для разгона предмета до столкновения с другим предметом. Скорость, с которой происходит <Color id="gold">столкновение</Color>, определяет успех создания нового предмета.

Хотя <Color id="aqua">ускоритель частиц</Color> можно использовать для нескольких рецептов, наиболее известное его применение — создание <Color id="gold">чёрной дыры</Color> путём столкновения <Color id="light_purple">маленького фрагмента Хаоса</Color> с <Color id="light_purple">гранулой антиматерии</Color> при минимальной энергии в <Color id="aqua">15 000 Дж</Color>.
