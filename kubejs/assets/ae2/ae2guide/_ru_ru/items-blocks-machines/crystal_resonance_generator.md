# Кристаллический резонирующий генератор

<BlockImage id="crystal_resonance_generator" scale="8" />

Это устройство может генерировать энергию для вашей сети МЭ без использования топлива. Из-за кристаллических вибраций, которые создаёт это устройство, только один генератор может быть использован в одной сети. От этих вибраций не защищает даже <ItemLink id="quartz_fiber" />.

**Скорость генерации:** <ae2:ConfigValue name="crystalResonanceGeneratorRate"/> AE/t

## Рецепт

Кристаллический резонирующий генератор делается не по стандартному рецепту крафта.
Вместо этого его нужно **создать в мировом двигателе** после того, как Вы получите **основное улучшение "Корпус механизма"**.
Пожалуйста, обратитесь к JEI за точным составом ингредиентов.

Подробности о разблокировке и использовании этой мощной системы крафта смотрите в [гайде по мировому двигателю](../world-engine.md).
